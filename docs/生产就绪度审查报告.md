## 四、安全发现

### 严重（必须修复后上线）

1. **默认管理员凭据无条件创建** — `main.py:274-338`，同 P0-1。注释自称「仅本地开发环境」但函数内无任何环境判断；`main.py:314` 日志明文打印密码。
2. **Agent 工具链可被用于 SSRF** — `config/agent.yaml:245-264` + `app/ai_service/mcp_manager.py:99-121`：`fetch` 无 `tools_include` 白名单全量暴露。任何已注册用户可通过聊天消息（或提前把恶意指令放进 RAG 文档/笔记，即间接提示注入）让 LLM 访问 `169.254.169.254`（云元数据）、内网 `192.168.x.x`、`localhost` 并把结果回传。修复：(1) `fetch` 加 `tools_include` 白名单；(2) 工具外层加 URL 守卫：拒绝私网/回环/链路本地地址（169.254/16、10/8、172.16/12、192.168/16、127/8、::1），仅允许 http/https；(3) 系统提示词收紧抓取权限。
